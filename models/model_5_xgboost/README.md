# Model 5 — XGBoost

XGBoost is the fourth and final traditional machine learning classifier in the current model comparison.

Like SVM, KNN, and Random Forest, XGBoost does **not** process the original paddy leaf images directly. It uses the **512-dimensional feature vectors extracted from the trained ResNet34 CNN**.

## Role in the Project

The XGBoost pipeline is:

Paddy Leaf Image
       ↓
   ResNet34 CNN
       ↓
512-D Feature Vector
       ↓
    XGBoost
       ↓
 Disease / Pest Class

ResNet34 performs the visual representation learning, while XGBoost performs the final classification using those learned features.

## Input

The model receives the 512-dimensional feature representation generated by ResNet34.

Training features   : 8,326 × 512
Validation features : 2,081 × 512

Each image is therefore represented by 512 numerical values rather than its original pixels.

## Why XGBoost?

XGBoost is a gradient-boosting algorithm based on decision trees.

It was included in this project because it provides a different tree-based approach from Random Forest.

While Random Forest builds many trees independently and combines their predictions, XGBoost builds trees sequentially, with later trees attempting to improve upon the errors made by earlier ones.

This makes XGBoost a useful model to compare against SVM, KNN, and Random Forest using the same ResNet34 feature representation.

# Configuration

The model was implemented using `xgboost.XGBClassifier`.

XGBClassifier(
    n_estimators=300,
    max_depth=6,

    subsample=0.8,
    colsample_bytree=0.8,
    objective='multi:softmax',
    num_class=10,
    eval_metric='mlogloss',
    random_state=42,
    n_jobs=-1
)

| Parameter            | Value           |
| -------------------- | --------------- |
| Algorithm            | XGBoost         |

| Maximum tree depth   | 6               |
| Learning rate        | 0.05            |
| Subsample            | 0.8             |

These settings were used directly to establish the baseline XGBoost result.

# Training

XGBoost is trained using the features generated by the ResNet34 feature-extraction stage.

X_train
   ↓
XGBoost
   ↓
300 boosted trees
   ↓
Multiclass prediction

The training set contains:

8,326 samples
512 features per sample

The trained model is then evaluated using:

2,081 validation samples

The same validation split is used by the other classical ML models.

# Results

XGBoost achieved:

## **76.17% Validation Accuracy**

| Metric         |       Result |
| -------------- | -----------: |
| Accuracy       |   **76.17%** |
| Macro F1       |   **0.7277** |
| Weighted F1    |   **0.7597** |
| Training Time  | **403.45 s** |
| Inference Time |   **0.17 s** |

These results were obtained on the project's 2,081-image validation set.

# Interpretation

XGBoost achieved the **second-highest accuracy among the four classical ML models**.

The classical model comparison is:

SVM              → 76.93%
XGBoost          → 76.17%
KNN              → 70.30%
Random Forest    → 69.73%

The difference between SVM and XGBoost is relatively small:

76.93% - 76.17% = 0.76 percentage points

This makes XGBoost a competitive classical alternative in the current experiment.

However, both models remain substantially below the fine-tuned ResNet34 baseline of **98.03% validation accuracy**.

# Training and Inference

One of the most noticeable characteristics of XGBoost in this experiment is its training time.

Training   : 403.45 seconds
Inference  : 0.17 seconds

The training time was significantly higher than the other classical models.

However, the measured inference time was the **fastest among the four classical models**.

This gives XGBoost an interesting trade-off:

Longer training
      ↓
Fast inference

For a system where the model is trained once and then used repeatedly for predictions, this trade-off may be acceptable.

# XGBoost vs Random Forest

Both XGBoost and Random Forest are tree-based models, but they approach the problem differently.

| Aspect         | Random Forest | XGBoost           |
| -------------- | ------------- | ----------------- |
| Main approach  | Bagging       | Gradient boosting |
| Trees          | 300           | 300               |
| Accuracy       | 69.73%        | **76.17%**        |
| Training time  | 47.01 s       | 403.45 s          |
| Inference time | 0.19 s        | **0.17 s**        |

In the current experiment, XGBoost achieved considerably higher accuracy than Random Forest, while also having a slightly faster measured inference time.

The trade-off was a much longer training time.

# Limitations

* No hyperparameter optimization was performed.
* Only one XGBoost configuration was evaluated.
* The model depends on ResNet34-generated features.
* The validation set is the only source of the reported accuracy.
* No real-world field-image evaluation has been performed.
* No verified score exists for the unlabeled Kaggle test set.
* The model has not yet been integrated into a standalone inference application.
