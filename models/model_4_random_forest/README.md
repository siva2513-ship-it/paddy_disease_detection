# Model 4 — Random Forest

Random Forest is the third traditional machine learning classifier evaluated in this project.

Instead of working directly with paddy leaf images, the Random Forest model uses the **512-dimensional feature vectors generated by the trained ResNet34 CNN**.

This experiment helps evaluate whether an ensemble of decision trees can effectively classify paddy diseases and pests using features learned by a deep learning model.

## Role in the Project

The Random Forest pipeline is:

Paddy Leaf Image
       ↓
   ResNet34 CNN
       ↓
512-D Feature Vector
       ↓
  Random Forest
       ↓
 Disease / Pest Class

The ResNet34 is responsible for extracting visual information from the image.

Random Forest then uses that numerical representation to make the final classification.

## Input

Random Forest receives the same feature representation used by the other classical ML models.

Training features   : 8,326 × 512
Validation features : 2,081 × 512

Each image is represented by **512 numerical features** extracted from the trained ResNet34 model.

The original image is not passed directly to the Random Forest classifier.

## Why Random Forest?

Random Forest is an ensemble learning algorithm that combines multiple decision trees to make predictions.

It was included in this project to compare a tree-based ensemble method against:

* SVM
* KNN
* XGBoost

This provides a broader comparison of different traditional ML approaches when working with the same CNN-generated feature representation.

# Configuration

The model was implemented using `sklearn.ensemble.RandomForestClassifier`.

RandomForestClassifier(
    n_estimators=300,
    class_weight='balanced',
    random_state=42,
    n_jobs=-1
)

| Parameter       | Value         |
| --------------- | ------------- |
| Algorithm       | Random Forest |
| Number of trees | 300           |
| Class weighting | `balanced`    |
| Random state    | 42            |
| Parallel jobs   | `-1`          |

### Why `class_weight='balanced'`?

The dataset contains an uneven number of images across the 10 classes.

The balanced class-weight option was used so that classes with fewer training examples receive greater importance during training.

No hyperparameter search was performed in the current experiment.

# Training

The Random Forest model is trained using the feature matrix generated during the feature-extraction stage.

X_train
   ↓
Random Forest
   ↓
300 Decision Trees
   ↓
Combined Prediction

The model uses:

8,326 training samples
512 features per sample

It is evaluated using:

2,081 validation samples

# Results

Random Forest achieved:

## **69.73% Validation Accuracy**

| Metric         |      Result |
| -------------- | ----------: |
| Accuracy       |  **69.73%** |
| Macro F1       |  **0.6478** |
| Weighted F1    |  **0.6908** |
| Training Time  | **47.01 s** |
| Inference Time |  **0.19 s** |

These results were obtained on the project's 2,081-image validation set.

# Interpretation

Among the four classical ML models tested in this project, Random Forest achieved the lowest validation accuracy.

The comparison was:

SVM              → 76.93%
XGBoost          → 76.17%
KNN              → 70.30%
Random Forest    → 69.73%

Random Forest therefore performed slightly below KNN and considerably below SVM and XGBoost.

However, the result is still useful because it shows how a tree-based ensemble behaves when applied to the same CNN-generated feature representation.

# Training and Inference

Random Forest required approximately:

Training   : 47.01 seconds
Inference  : 0.19 seconds

This makes the model an interesting example of the trade-off between training cost and prediction speed.

# Relationship with ResNet34

Random Forest depends on the feature representation produced by Model 1.

              ResNet34
                 │
                 ▼
          512-D Features
                 │
                 ▼
          Random Forest
                 │
                 ▼
       Disease / Pest Class

The Random Forest model therefore cannot be considered an independent image-classification model.

If the ResNet34 feature extractor is retrained or replaced, the Random Forest classifier would need to be retrained using the corresponding feature representation.

# Limitations

* No hyperparameter optimization was performed.
* Only one Random Forest configuration was evaluated.
* The model depends on the ResNet34 feature representation.
* The validation results may not represent performance on real field images.
* No verified evaluation is available for the unlabeled Kaggle test set.
* The current model has not been integrated into a standalone inference application.

# Key Observation

Random Forest demonstrates that a tree-based ensemble can classify the learned CNN features, but its current configuration does not match the performance of SVM or XGBoost.

The model achieved:

> **69.73% validation accuracy**

while maintaining a relatively fast measured inference time of:

> **0.19 seconds for 2,081 validation samples**

Therefore, its main value in this project is as a meaningful comparison against the other classical ML approaches rather than as the current best-performing classifier.

# Summary

Random Forest provides a tree-based ensemble perspective on the 512-dimensional feature representation learned by ResNet34.
