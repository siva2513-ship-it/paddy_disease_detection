# Model 2 — Support Vector Machine (SVM)

The Support Vector Machine (SVM) is the first traditional machine learning classifier evaluated in this project.

Unlike the ResNet34 model, SVM does not work directly with the original paddy leaf images. Instead, it receives the **512-dimensional feature vectors extracted from the trained ResNet34 model**.

This experiment helps answer an important question:

How well can a traditional machine learning classifier perform when it is given visual features learned by a deep CNN?

## Role in the Project

The overall process for this model is:

Paddy Leaf Image
       ↓
   ResNet34 CNN
       ↓
512-D Feature Vector
       ↓
      SVM
       ↓
 Disease / Pest Class

The ResNet34 handles the visual feature learning, while the SVM handles the final classification.

This makes the SVM experiment different from the ResNet34 baseline, where the CNN itself performs both feature learning and classification.

## Input

The SVM receives a numerical feature vector containing:

512 features per image

The feature vectors are generated by the trained ResNet34 model.

The datasets used by the notebook are:

Training features   : 8,326 × 512
Validation features : 2,081 × 512

The SVM therefore never needs to process the original image pixels directly.

## Why SVM?

SVMs are widely used for classification problems where the input is represented as a numerical feature vector.

In this project, the CNN has already learned useful visual information from the paddy images. SVM provides a way to test whether a traditional classifier can effectively separate the disease/pest classes using those learned representations.

# Configuration

The model was implemented using `sklearn.svm.SVC`.

SVC(
    kernel='rbf',
    C=10,
    gamma='scale',
    probability=True,
    random_state=42
)

| Parameter    | Value   |
| ------------ | ------- |
| Algorithm    | SVM     |
| Kernel       | RBF     |
| C            | 10      |
| Gamma        | `scale` |
| Probability  | `True`  |
| Random state | 42      |

No hyperparameter search was performed for this experiment. These values were used directly during training.

# Training

The SVM is trained using the extracted ResNet34 features:

X_train
   ↓
SVM
   ↓
Trained classifier

The training data contains:

8,326 samples
512 features per sample

The model is then evaluated on the separate:

2,081 validation samples

The same validation split is used by the other classical ML models, allowing a direct comparison.

# Results

The SVM achieved:

## **76.93% Validation Accuracy**

| Metric         |       Result |
| -------------- | -----------: |
| Accuracy       |   **76.93%** |
| Macro F1       |   **0.7281** |
| Weighted F1    |   **0.7657** |
| Training Time  | **102.67 s** |
| Inference Time |  **10.23 s** |

All results were obtained using the project's 2,081-image validation set.

# Interpretation

Among the four classical machine learning models tested in this project, **SVM achieved the highest validation accuracy**.

SVM        → 76.93%
XGBoost    → 76.17%
KNN        → 70.30%
RandomForest → 69.73%

The result shows that SVM can make reasonably effective use of the visual representation learned by ResNet34.

However, it still performs substantially below the fine-tuned ResNet34 baseline, which achieved:

ResNet34 → 98.03%
SVM      → 76.93%

This suggests that the end-to-end CNN is better able to adapt its learned representation specifically for the final classification task in this experiment.

# Training and Inference

The SVM required approximately:

Training   : 102.67 seconds
Inference  : 10.23 seconds

The training time is moderate compared with the other classical models.

However, its measured inference time was considerably higher than Random Forest and XGBoost for the same validation set.

This is an important practical consideration if the classifier is eventually used in a real-time application.

# Relationship with ResNet34

SVM is dependent on Model 1.

Model 1
ResNet34
   │
   ▼
512-D Features
   │
   ▼
Model 2
SVM

If the ResNet34 feature representation changes, the SVM model would need to be retrained using the new features.

Therefore, this model should be considered a **classifier built on top of the ResNet34 representation**, rather than a standalone image-classification model.

# Limitations

* No hyperparameter optimization was performed.
* The SVM was evaluated only on the project's validation split.
* The model does not process raw images directly.
* Its performance depends on the quality of the ResNet34 features.
* No real-world field-image evaluation has been performed.
* No verified accuracy is available for the unlabeled Kaggle test set.

SVM achieved the **best result among the four traditional ML classifiers** tested on ResNet34's 512-dimensional feature representation.

### Final Result

> **76.93% validation accuracy**

While this is lower than the **98.03% ResNet34 baseline**, the experiment demonstrates that a traditional classifier can still make useful predictions using features learned by a CNN.
