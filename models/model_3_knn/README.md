# Model 3 — K-Nearest Neighbors (KNN)

K-Nearest Neighbors (KNN) is the second traditional machine learning classifier evaluated in this project.

Like SVM, KNN does not work directly with the original paddy leaf images. Instead, it uses the **512-dimensional feature representations extracted from the trained ResNet34 CNN**.

## Role in the Project

The KNN pipeline is:

Paddy Leaf Image
       ↓
   ResNet34 CNN
       ↓
512-D Feature Vector
       ↓
      KNN
       ↓
 Disease / Pest Class

ResNet34 is responsible for learning the visual representation, while KNN uses the resulting numerical features to make the final classification.

## Input

KNN receives a **512-dimensional feature vector** for every image.

The feature data used by this model is:

Training features   : 8,326 × 512
Validation features : 2,081 × 512

The original images are not passed directly to KNN.

The feature vectors are generated by the ResNet34 feature-extraction pipeline.

## Why KNN?

KNN is a simple and intuitive classification algorithm based on similarity.

For a new feature vector, KNN looks at nearby training samples and uses their classes to determine the prediction.

This makes it useful as a baseline for understanding whether visually similar ResNet34 representations also tend to belong to the same disease or pest class.

Unlike models such as SVM, Random Forest, and XGBoost, KNN does not learn a complex set of parameters during a conventional training process. Instead, it stores the training examples and performs the main computation when making predictions.

# Configuration

The model was implemented using `sklearn.neighbors.KNeighborsClassifier`.

```python
KNeighborsClassifier(
    n_neighbors=5,
    weights='distance',
    metric='euclidean',
    n_jobs=-1
)
```

| Parameter           | Value     |
| ------------------- | --------- |
| Algorithm           | KNN       |
| Number of neighbors | 5         |
| Weights             | Distance  |
| Distance metric     | Euclidean |
| Parallel jobs       | `-1`      |

### What these settings mean

**`n_neighbors=5`**

The classifier considers the five nearest training samples when making a prediction.

**`weights='distance'`**

Closer neighbors have more influence on the final prediction than farther neighbors.

**`metric='euclidean'`**

Euclidean distance is used to measure similarity between feature vectors.

**`n_jobs=-1`**

Available CPU cores are used during prediction.

No hyperparameter search was performed for this experiment.

# Training

KNN has very little conventional training compared with models such as Random Forest or XGBoost.

The classifier is fitted using the extracted training features:

X_train
   ↓
KNN
   ↓
Stored training representation

The validation set is then used to generate predictions.

X_valid
   ↓
Find nearest training samples
   ↓
Compare their classes
   ↓
Predicted class

The model uses:

8,326 training samples
512 features per sample

and is evaluated on:

2,081 validation samples

# Results

KNN achieved:

## **70.30% Validation Accuracy**

| Metric         |     Result |
| -------------- | ---------: |
| Accuracy       | **70.30%** |
| Macro F1       | **0.6599** |
| Weighted F1    | **0.7007** |
| Training Time  | **0.01 s** |
| Inference Time | **3.30 s** |

The results were obtained using the same 2,081-image validation set used for the other models.

# Interpretation

KNN achieved lower accuracy than SVM and XGBoost in this experiment.

The four classical models performed as follows:

SVM              → 76.93%
XGBoost          → 76.17%
KNN              → 70.30%
Random Forest    → 69.73%

KNN therefore ranks **third among the four classical models**.

However, the result is still useful because it provides a different perspective on the ResNet34 feature space.

The model demonstrates that simple nearest-neighbor relationships in the 512-dimensional feature representation contain useful disease and pest information, but they are not sufficient to achieve the same classification performance as the fine-tuned ResNet34 or the better-performing classical classifiers.

# Training vs Inference

One of KNN's most noticeable characteristics in this experiment is the difference between training and inference time.

Training   : 0.01 seconds
Inference  : 3.30 seconds

The extremely small training time is expected because KNN does not build a complex predictive model during fitting.

The computational work is largely performed during prediction, where validation samples are compared with the stored training samples.

This makes KNN simple to train, but its inference cost can become an important consideration as the dataset grows.

# Limitations

* No hyperparameter optimization was performed.
* Only one neighbor configuration was evaluated.
* The model depends entirely on the quality of the ResNet34 features.
* Prediction requires comparisons with the training feature set.
* Evaluation was performed on the internal validation set.
* No real-world field-image evaluation has been performed.
* No verified score exists for the unlabeled Kaggle test set.

# Possible Improvements

Future experiments could investigate:

* Different values of `n_neighbors`.
* Uniform versus distance-based weighting.
* Alternative distance metrics.
* Feature scaling.
* PCA or other dimensionality-reduction techniques.
* Comparing optimized KNN against optimized SVM and XGBoost.
* Testing inference performance with larger datasets.

These experiments are not part of the current implementation and would be future work.

# Key Observation

KNN was the **fastest model to fit** among the four classical ML models:

> **Training time: 0.01 seconds**

However, this does not mean that KNN is the fastest overall model for deployment.

Its inference time was:

> **3.30 seconds for 2,081 validation samples**

because predictions require finding neighboring training samples.

Very little training
        ↓
More computation during prediction

# Summary

KNN provides a simple distance-based baseline for the 512-dimensional representations learned by ResNet34.

### Final Result

> **70.30% validation accuracy**

Although KNN did not perform as well as SVM or XGBoost in this experiment, it provides a useful comparison and demonstrates that the ResNet34 feature space contains meaningful information that can be used by traditional machine learning algorithms.
